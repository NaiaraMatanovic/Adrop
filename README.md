# Adrop

> Tornar leve e acessível, uma gota por vez, o conhecimento que ajuda as pessoas a crescer.

A **Adrop** é um blog de ensino que explica, de forma simples e didática, temas de
crescimento pessoal: neurociência, filosofia, psicologia, organização pessoal e afins.
O ponto de partida são aprendizados vindos de livros, sem se restringir a eles.

## Por que "Adrop"?

*A drop*, uma gota:

- **O mar e a gota:** o conhecimento é infinito e aprendemos uma gota por vez.
- **A gota que transborda o copo:** o esforço de aprender se acumula e pode virar a chave para uma mudança de vida.
- **Leveza:** transformar conhecimentos pesados em algo leve e fácil de digerir.

## O que faz

- Apresenta a Adrop e lista os posts, dos mais recentes para os mais antigos, em cards com capa, resumo e botão "Ler mais".
- Oferece páginas de leitura para cada post, com título, data, tema e autor.
- Tem uma página "Sobre", com quem escreve e o significado do nome.
- Traz um cabeçalho com o nome "Adrop" e o menu "Sobre" em todas as páginas.
- Funciona bem no celular e no computador.
- Fica publicada num link público, pelo GitHub Pages.

## Para quem

Estudantes e leitores em geral interessados em crescimento pessoal que querem entender
essas ideias sem precisar ler o livro inteiro nem decifrar termos técnicos.

## Stack

- HTML
- CSS
- Git e GitHub
- GitHub Pages (hospedagem)

## Evolução

O projeto cresce em fases: blog estático, interatividade com JavaScript, componentes
com React, versão fullstack com Node e banco de dados e, por fim, uma área para a
autora escrever e publicar sem mexer no código.
